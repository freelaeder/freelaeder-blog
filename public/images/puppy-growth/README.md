# 小狗成长相册图片与视频

`/puppy-growth` 页面会在开发启动或构建时自动扫描这个目录，图片名称和后缀不需要固定。

图片格式：`.avif`、`.gif`、`.jpg`、`.jpeg`、`.jfif`、`.png`、`.svg`、`.webp`。

视频格式：`.mp4`、`.webm`、`.mov`、`.m4v`、`.ogv`。建议优先使用浏览器兼容性更好的 H.264 编码 `.mp4`。视频进入高亮位置后会自动静音播放，播放期间暂停计时轮播，播放完成后自动切换到下一项。

图片的数字序号、加入日期和当时年龄保存在 `image-age-records.json`。页面按照记录中的序号播放，并根据真实年龄自动放入 `0—3 个月`、`3—12 个月` 或 `1 岁以后` 分组，不再按图片数量平均分组。

新增图片后运行 `npm run puppy:sync`，脚本只会创建新的序号，并将日期标记为“待记录”，不会猜测拍摄日期。把对应记录的 `capturedOn` 改成实际日期后，再次同步即可计算真实年龄。`npm run dev`、`npm run dev:watch` 与 `npm run build` 也会自动执行同步。

如果照片不是当天拍摄，可直接修改对应记录的 `capturedOn`（格式为 `YYYY-MM-DD`）；下次同步时会自动重新计算 `age`。图片可以放在当前目录或任意子目录，文件名和后缀都不要求固定。
